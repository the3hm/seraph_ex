# Product Context

## Product Vision
ExVenture is a modern text-based MMO server that combines the classic MUD gaming experience with contemporary web technologies and development practices. It aims to make MUD development and administration accessible while maintaining the depth and complexity that makes text-based games engaging.

## Core User Groups

### Players
- Experience rich text-based gameplay
- Access through traditional telnet or modern web client
- Participate in cross-game community features
- Secure account management with 2FA

### Game Administrators
- Complete game management through web interface
- Real-time content updates without server restarts
- Comprehensive monitoring and metrics
- Easy-to-use tools for world building

### Developers
- Clear, modular codebase
- Extensive documentation
- Test-driven development support
- Flexible deployment options

## Feature Sets

### Game World
1. **Content Management**
   - Zones and rooms
   - NPCs and items
   - Quests and events
   - Classes and races
   - Skills and effects

2. **Dynamic Content**
   - Live updates
   - Event scripting
   - NPC behaviors
   - Quest chains

### Player Experience
1. **Character Development**
   - Class-based progression
   - Skill systems
   - Equipment management
   - Quest completion

2. **Social Features**
   - Cross-game chat
   - Player messaging
   - Social commands
   - Community integration

### Administration
1. **Web Dashboard**
   - Content creation tools
   - Player management
   - System monitoring
   - Configuration controls

2. **Game Management**
   - Real-time updates
   - Content deployment
   - Player moderation
   - System maintenance
